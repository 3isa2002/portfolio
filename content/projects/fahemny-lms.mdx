## Problem

A small e-learning platform where students can sign up, browse programming and computer-science
courses, and test themselves.

## Approach

ASP.NET Core MVC on .NET 8, with Entity Framework Core over SQL Server:

- Registration and login with BCrypt-hashed passwords, anti-forgery (CSRF) protection and
  server-side validation.
- Course pages for Java, Web Design, Data Structures, C++ and Computer Security, each with a quiz.

## Result

A two-person project; I worked across controllers, views and the data layer.
