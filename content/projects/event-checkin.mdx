## Problem

Guests arriving at several gates, each with their own invitation codes, and no budget or time for
dedicated event software.

## Approach

A small Flask app the gate staff open in a browser: scan a QR code with the device camera
(html5-qrcode) or type the code, pick the gate, and see immediately whether the code was already
used, and when and at which gate. A live table lists everyone checked in, and the form is
validated on the server.

## Result

Built in an evening and used at the actual event. Check-ins are stored in a plain file, which was
right for one event with one machine per gate, and is the first thing to change for anything bigger.
