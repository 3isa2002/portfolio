## Problem

A small robot needed smooth, repeatable motor speed under changing load, controllable from a main computer over CAN.

## Approach

A PID loop runs in a timer interrupt; FreeRTOS tasks handle CAN messages, telemetry and fault detection
so the control loop is never blocked.

```c title="pid.c"
float pid_step(pid_t *p, float setpoint, float measured) {
    float err = setpoint - measured;
    p->integral += err * p->dt;
    float out = p->kp * err + p->ki * p->integral + p->kd * (err - p->prev) / p->dt;
    p->prev = err;
    return clamp(out, p->min, p->max);
}
```

## Result

Speed holds within 1% of the target under load steps, and the board reports faults over CAN within one cycle.
