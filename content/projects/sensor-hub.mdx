## Problem

I wanted to see temperature and humidity in every room and switch a fan remotely, without a cloud subscription.

## Approach

Battery-powered ESP32 nodes wake every 10 seconds, read their sensors and publish to a local MQTT broker.
A dashboard subscribes to the topics and can toggle a relay node.

```cpp title="node.ino"
void loop() {
  float t = sensor.readTemperature();
  float h = sensor.readHumidity();
  mqtt.publish("home/livingroom/climate", payload(t, h));
  esp_deep_sleep(10 * 1000000ULL);
}
```

## Result

Four nodes have run for months on a single charge, and the dashboard updates live on any device on the network.
